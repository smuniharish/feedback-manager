# Example: `create_agent` + real MCP tools

Source file: `examples/07_agent_mcp_create_agent.py`

This example wires `langchain.agents.create_agent` to two real, running [Model Context Protocol](https://modelcontextprotocol.io/) servers -- the reference filesystem server and the reference Playwright (browser automation) server -- loaded via `langchain-mcp-adapters`, and drives the agent with a real hosted LLM. Feedback capture uses nothing beyond `feedback-manager`'s existing LangChain integration.

Key pattern -- loading real MCP tools and wiring feedback capture into the agent:

```python
from langchain.agents import create_agent
from langchain_mcp_adapters.client import MultiServerMCPClient
from feedback_manager.integrations.langchain import FeedbackCallbackHandler

client = MultiServerMCPClient({
    "filesystem": {"transport": "stdio", "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", workspace_dir]},
    "playwright": {"transport": "stdio", "command": "npx", "args": ["-y", "@playwright/mcp@latest", "--headless"]},
})
tools = await client.get_tools()

agent = create_agent(model=llm, tools=tools, system_prompt="...")
handler = FeedbackCallbackHandler(manager)
result = await agent.ainvoke({"messages": [...]}, config={"callbacks": [handler]})
```

An `EVALUATOR`-sourced `QUALITY` feedback event is then submitted based on whether the agent's answer actually reflects the file it was asked to read -- an automated quality check independent of any tool failures the callback handler may have already captured.
