# Getting started

Three steps, from install to a first resolved piece of feedback. None of them
needs an external service.

<div class="grid cards" markdown>

-   :material-download:{ .lg .middle } __[Installation](installation.md)__

    ---

    Install the core, or add the LangChain extra and the LanceDB, LadybugDB
    and OpenTelemetry extras you use.

-   :material-rocket-launch:{ .lg .middle } __[Quickstart](quickstart.md)__

    ---

    Submit feedback with the execution it is about, route it to a handler,
    and move it through its lifecycle.

-   :material-tune:{ .lg .middle } __[Configuration](configuration.md)__

    ---

    Choose the store, failure modes, policies, learning and observability for
    each manager, in code.

</div>

After the quickstart, [Concepts](../concepts/index.md) explains the feedback
model and the feedback-to-learning loop, and the
[how-to guides](../how-to/index.md) walk through common tasks.
